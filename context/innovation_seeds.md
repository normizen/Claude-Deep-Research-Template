# Innovation Seeds — Domain Matrix

## Verwendungsanleitung (für den Domain Matrix Seeder)

Diese Datei enthält 30 exotische Wissensdomänen als Inspirationsmatrix für das Strategic-Innovation-System. Der Domain Matrix Seeder (Phase 2) liest diese Datei und wählt 2 Domänen für die aktuelle Session.

**Auswahl-Prozess:**
1. Lies das Verwendungs-Tracking unten
2. Wende das Anti-Anchor-Protokoll an (Ausschlüsse zuerst)
3. Wähle 2 Domänen aus verschiedenen Clustern
4. Begründe die Auswahl explizit in `scratchpad/[SLUG]-domain-selection.md`
5. Aktualisiere das Verwendungs-Tracking nach der Auswahl

---

## Anti-Anchor-Protokoll

**Pflichtregeln für den Seeder:**
1. Schließe alle Domänen-Kombos aus, die in den **letzten 3 Sessions** verwendet wurden
2. Schließe alle Kombos aus, die bereits in diesem Cluster laut `idea-outcomes.md` versucht wurden
3. Priorisiere Domänen mit dem höchsten Wert bei "Tage seit letzter Verwendung"
4. Falls alle Domänen kürzlich verwendet: wähle die am längsten zurückliegenden
5. Die zwei gewählten Domänen müssen aus **verschiedenen Clustern** stammen
6. Mindestens eine der gewählten Domänen soll maximalen strukturellen Kontrast zur Kerndomäne haben

**Negative Constraints (immer aktiv):**
- Keine zwei Domänen aus dem gleichen Cluster
- Keine offensichtlich "passenden" Domänen zur Kerndomäne wählen — Kontrast ist das Ziel
- Standard-Analogien (Spieltheorie, Thermodynamik) nur wenn kein anderes Cluster verfügbar
